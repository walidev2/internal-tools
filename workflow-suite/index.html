Two things to hold under pressure

Promise / measure

We accept accountability for the operating system we install: coverage, response time, decision ownership, escalation integrity.

We measure the business effect — review volume, rating trajectory, accuracy incidents — without pretending the system controls customers or platforms.

Rep line: At Day 90 we show both — whether the workflow ran as designed, and what changed around it.

Never say
"What it produces depends on how you run it."

Reversibility

The prior operating process is documented before deployment. The installed operating model can be rolled back within the defined window; public actions already taken are not guaranteed to reverse.

Hold this line
Rollback is an operating remedy, not a refund mechanism.

The operating model is reversible. The proof accumulated while it ran is permanent.
